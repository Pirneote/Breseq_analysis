Script to run BRESEQ on HPC cluster

breseq.sh --> run one job

breseq_Pp.sh --> run multiple jobs
files structure:
  Condition1_rep1_READ1.fasta.gz
  Condition1_rep1_READ2.fasta.gz
  Condition1_rep2_READ1.fasta.gz
  Condition1_rep2_READ2.fasta.gz
  Condition2_rep1_READ1.fasta.gz
  Condition2_rep1_READ2.fasta.gz
  ......
  ......

Jupyter notebook to analyze BRESEQ output for all conditions and generate heatmaps to visualize de novo mutations.
